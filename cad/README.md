# CAD 파일

OpenSCAD 소스(.scad)가 원본이고 STL은 렌더링 결과물이다.
OpenSCAD는 openscad.org에서 무료 설치. .scad 열어서 상단 변수 수정 →
F6(렌더) → STL 내보내기.

## 파일

- arc_scan_servo_stand.scad / .stl — MG996R 스탠드. 표준 치수 기반이라 **바로 출력 가능**
- arc_scan_mast.scad — 센서 마스트. **실측 4개 값 수정 후 렌더링할 것**
- arc_scan_mast_DEFAULT_DIMS.stl — 미실측 기본값 렌더링. 참고용, 출력 금지

## 마스트 실측 항목 (센서 보드에서 캘리퍼스나 자로)

1. sens_hole_span — 양쪽 나사구멍 중심 간 거리
2. sens_hole_d — 나사구멍 지름 (사용할 나사에 맞게, M2 셀프태핑이면 1.8~2.0)
3. sens_board_len — 보드 긴 변
4. sens_board_wid — 보드 짧은 변

서보 혼 값(horn_*)은 원형 혼 실물 기준으로 확인.

## 출력 설정 권장

- 재료: PLA면 충분
- 레이어: 0.2mm, 인필: 30~40%
- 서보 스탠드: 그대로 바닥에 놓고 출력, 서포트 불필요
- 마스트: 세워서 출력 (바닥 디스크가 베드), 서포트 불필요하게 설계됨.
  틸트면 오버행 최대 30°라 쿨링만 정상이면 깨끗하게 나옴
- 마스트 높이 약 195mm — 출력 시간 수 시간 예상
