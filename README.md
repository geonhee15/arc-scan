# ARC Scan

**A**mbient **R**oom **C**artographer — 회전식 ToF 라이다로 방을 3D 포인트 클라우드로 스캔하는 프로젝트.

VL53L1X ToF 센서 7개를 수직 마스트에 각도를 분산해 장착하고, 서보로 회전시키며
방 전체의 거리 데이터를 수집한다. ESP32가 WiFi 웹소켓으로 스트리밍하고
브라우저에서 three.js로 포인트 클라우드를 실시간 렌더링한다.

## 하드웨어

| 부품 | 수량 | 역할 |
|---|---|---|
| ESP32 DevKit (WROOM-32) | 1 | 메인 컨트롤러 |
| VL53L1X 브레이크아웃 (VL53L0/1XV2 보드) | 7 | ToF 거리 센서 (최대 4m) |
| TCA9548A I2C 멀티플렉서 | 1 | 센서 주소 충돌 해결 (전부 0x29 고정이라 필수) |
| MG996R 서보 | 1 | 회전부 (v1: 180° 스캔) |
| LiPo 503035 500mAh | 1 | 배터리 구동 (마감 단계) |

v2에서 28BYJ-48 스테퍼 + ULN2003A로 교체해 360° 스캔 예정.

## 진행 상황

- [x] 0단계: 부품 확인
- [x] 1단계 (진행 중): 센서 1개 + 멀티플렉서 채널 0 인식 성공
- [x] 1단계: 센서 2개 순회 폴링 검증
- [ ] 1단계: 7개 전 채널 순회 폴링
- [ ] 2단계: WiFi 웹소켓 + three.js 시각화
- [ ] 3단계: 마스트/브라켓 3D 프린팅
- [ ] 4단계: 서보 동기화, 구면좌표 변환, 첫 스캔
- [ ] 5단계: 색상 매핑, 배터리 구동, 데모 영상
