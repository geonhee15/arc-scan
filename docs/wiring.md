# 배선표

## 1단계: WROOM + TCA9548A + 센서 1개 (채널 0)

전원은 전부 3.3V. **5V 금지** (TCA, 센서 모두).

### 전원 레일

| 연결 | 대상 |
|---|---|
| WROOM 3V3 | 브레드보드 빨간(+) 레일 |
| WROOM GND | 파란(−) 레일 |

### TCA9548A

| TCA 핀 | 연결 |
|---|---|
| VIN | 빨간 레일 (3.3V) |
| GND | 파란 레일 |
| A0, A1, A2 | 전부 파란 레일 → 주소 0x70 고정 |
| SDA | WROOM GPIO21 |
| SCL | WROOM GPIO22 |

### VL53L1X (채널 0)

| 센서 핀 | 연결 |
|---|---|
| VIN | 빨간 레일 (3.3V) |
| GND | 파란 레일 |
| SCL | TCA SC0 |
| SDA | TCA SD0 |
| GPIO1, XSHUT | 미연결 |

⚠️ 이 센서 보드는 핀 인쇄 순서가 **VIN, GND, SCL, SDA** 순.
SCL이 SDA보다 먼저라 교차 실수하기 딱 좋음 (실제로 한 번 함, troubleshooting.md 참고).

## 예정 (7센서 확장 시)

센서 2~7을 SD1/SC1 ~ SD6/SC6에 동일 방식으로 추가.
채널 번호 = 마스트 위치 매핑: 채널 0 = 최상단 +30°, 채널 6 = 최하단 −30°, 10° 간격.

## 예정 (서보)

| MG996R | 연결 |
|---|---|
| 빨강 | WROOM VIN (USB 5V) |
| 갈색 | 파란 레일 (GND 공통 필수) |
| 주황 (신호) | GPIO13 |

서보 구동 시 전류 스파이크로 보드 리셋되면 서보 전원만 외부 5V로 분리.

### VL53L1X (채널 1) — 채널 0과 동일 패턴

| 센서 핀 | 연결 |
|---|---|
| VIN | 빨간 레일 (3.3V) |
| GND | 파란 레일 |
| SCL | TCA SC1 |
| SDA | TCA SD1 |
| GPIO1, XSHUT | 미연결 |

검증: 두 채널 모두 천장 거리 ~1720mm 일치 출력 확인 (2026-08-09)
