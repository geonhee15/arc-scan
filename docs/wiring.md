# 배선표

## 1단계: WROOM + TCA9548A + 센서 1개 (채널 0)

전원은 전부 3.3V. **5V 금지** (TCA, 센서 모두).

### 전원 레일

| 연결 | 대상 |
|---|---|
| WROOM 3V3 | 브레드보드 빨간(+) 레일 |
| WROOM GND | 파란(−) 레일 |

### TCA9548A

| TCA 핀 | 연결 |
|---|---|
| VIN | 빨간 레일 (3.3V) |
| GND | 파란 레일 |
| A0, A1, A2 | 전부 파란 레일 → 주소 0x70 고정 |
| SDA | WROOM GPIO21 |
| SCL | WROOM GPIO22 |

### VL53L1X (채널 0)

| 센서 핀 | 연결 |
|---|---|
| VIN | 빨간 레일 (3.3V) |
| GND | 파란 레일 |
| SCL | TCA SC0 |
| SDA | TCA SD0 |
| GPIO1, XSHUT | 미연결 |

⚠️ 이 센서 보드는 핀 인쇄 순서가 **VIN, GND, SCL, SDA** 순.
SCL이 SDA보다 먼저라 교차 실수하기 딱 좋음 (실제로 한 번 함, troubleshooting.md 참고).

## 예정 (7센서 확장 시)

센서 2~7을 SD1/SC1 ~ SD6/SC6에 동일 방식으로 추가.
채널 번호 = 마스트 위치 매핑: 채널 0 = 최상단 +30°, 채널 6 = 최하단 −30°, 10° 간격.

## 예정 (서보)

| MG996R | 연결 |
|---|---|
| 빨강 | WROOM VIN (USB 5V) |
| 갈색 | 파란 레일 (GND 공통 필수) |
| 주황 (신호) | GPIO13 |

서보 구동 시 전류 스파이크로 보드 리셋되면 서보 전원만 외부 5V로 분리.

### VL53L1X (채널 1) — 채널 0과 동일 패턴

| 센서 핀 | 연결 |
|---|---|
| VIN | 빨간 레일 (3.3V) |
| GND | 파란 레일 |
| SCL | TCA SC1 |
| SDA | TCA SD1 |
| GPIO1, XSHUT | 미연결 |

검증: 두 채널 모두 천장 거리 ~1720mm 일치 출력 확인 (2026-08-09)

### VL53L1X (채널 2) — 동일 패턴, 센서 전용 브레드보드로 분리

센서 3개째부터 두 번째 브레드보드에 센서 전용 배치.
보드 1(WROOM+TCA)의 전원 레일에서 점퍼선 2가닥으로 보드 2 레일 연장,
센서들의 VIN/GND는 보드 2 레일에서 공급.

| 센서 핀 | 연결 |
|---|---|
| VIN / GND | 보드 2 레일 (보드 1에서 연장) |
| SCL | TCA SC2 |
| SDA | TCA SD2 |

검증: 3채널 모두 천장 ~1710~1725mm 일치 (2026-08-09)

### VL53L1X (채널 5, 6) — 동일 패턴

| 센서 | SCL | SDA |
|---|---|---|
| 채널 5 | TCA SC5 | TCA SD5 |
| 채널 6 | TCA SC6 | TCA SD6 |

검증: 7채널 전부 동시 폴링 정상 (2026-08-09). **1단계 완료.**

### 서보 전원 구성 (확정)

| MG996R | 연결 |
|---|---|
| 주황 (신호) | WROOM GPIO13 |
| 빨강 (전원) | 외부 5V (폰 충전기 2A, USB 케이블 개조) — **WROOM VIN 아님** |
| 갈색 (GND) | 브레드보드 GND 레일 (충전기 GND와 공통 접지) |

USB 단일 전원으로는 brownout 발생 (troubleshooting.md 참고).
