# 트러블슈팅 기록

증상 → 원인 → 해결 형식. 날짜순.

## 2026-08-09

### 납땜 브릿지 (XIAO, 센서 헤더)

- **증상**: 납땜 시 옆 핀끼리 납이 계속 붙음
- **원인**: 납 공급량 과다 + 인두를 오래 대고 있음
- **해결**: 납량을 절반 이하로 줄이고, 납선이 녹기 시작하면 1초 안에 뗌.
  이미 붙은 브릿지는 깨끗한 맨 팁으로 핀 사이를 긁어내리면 갈라짐.
  다음 구매: 솔더윅, 플럭스 펜, 0.6~0.8mm 납선

### 센서 초기화 실패

- **증상**: `sensor.init()` 실패, "센서 초기화 실패! 배선 확인" 출력
- **진단**: I2C 스캐너(diagnostics/i2c_scan)로 단계 분리.
  메인 버스에서 0x70(TCA) 발견 → WROOM↔TCA 구간 정상.
  채널 0 열고 0x29 응답 없음 → TCA↔센서 구간 문제로 특정
- **원인**: 센서 보드 핀 순서가 VIN, GND, **SCL, SDA**인데
  SDA/SCL을 교차해서 연결함
- **해결**: 센서 SCL↔TCA SC0, 센서 SDA↔TCA SD0으로 교정
- **교훈**: 브레이크아웃 보드마다 핀 순서 다름. 인쇄 글자 기준으로 연결할 것

### 메모

- 센서 보드 실크가 "VL53L0/1XV2" — L0X/L1X 공용 기판이라 칩 종류는
  코드로 판별해야 함. L1X 라이브러리 init 성공 여부로 확인 예정

### 채널 1 초기화 실패 (센서 2개째 추가 시)

- **증상**: `채널 1 초기화 실패!` — 채널 0은 정상 통과
- **범위 특정**: 채널 0 통과 = WROOM/TCA/코드 정상 → 새로 추가한
  채널 1 라인(배선, 납땜, 센서)만 조사
- **원인/해결**: 두 번째 센서 라인 배선 문제 확인 후 교정, 재실행으로 해결
- **교훈**: 센서를 하나씩 추가하면 실패 시 용의자가 방금 추가한 라인
  하나로 좁혀진다. 7개 한 번에 꽂았으면 못 찾았을 것

### 측정값 0의 의미

- **증상**: 센서를 손으로 가리거나 렌즈에 밀착 시 0 또는 한 자리 수 출력
- **원인**: 고장 아님. VL53L1X는 측정 실패(범위 이탈, 반사 부족)를 0으로 반환
- **처리 방침**: 스캔 파이프라인에서 0은 무효 포인트로 버린다 (포인트 클라우드 미포함)

### 채널 4 초기화 실패 — 복합 원인 (2연타 버그)

- **증상**: `채널 4 초기화 실패!`. 센서 맞교환 테스트로 센서는 무죄,
  채널 4 경로 문제로 특정. 그런데 배선을 고쳐도 계속 실패
- **원인 A**: 채널 4 배선이 ESP32 핀과 같은 가로줄에 꽂혀 있었음 (SD5 라인 충돌)
- **원인 B**: A를 고치려고 ESP32 위치를 옮기는 과정에서 GPIO21에 SCL,
  GPIO22에 SDA를 교차로 재연결 (2차 사고)
- **해결**: A 교정 후에도 실패 → 수리 중 건드린 부분을 재점검 → B 발견, 교정 후 5채널 정상
- **교훈**:
  1. 원인이 2개 겹치면 하나를 고쳐도 증상이 그대로라 "고친 게 맞나"를 의심하게 됨.
     고쳤는데도 안 되면, 고치면서 새로 건드린 곳부터 의심할 것
  2. 부품을 옮겨 꽂으면 그 부품의 기존 배선 전체가 재검증 대상이 된다

## 2026-08-10

### Brownout detector was triggered (서보 기동 시 리셋)

- **증상**: 서보 스윕 시작 순간 시리얼에 `Brownout detector was triggered` 출력 후
  ESP32 재부팅 반복
- **원인**: MG996R 기동전류(1A+)를 USB 5V(WROOM VIN 경유)가 감당 못 해
  순간 전압 강하 → ESP32 저전압 보호 리셋
- **해결**: 서보 전원 분리. USB 케이블을 잘라 폰 충전기(2A)에서 5V/GND를 따고,
  서보 빨강은 충전기 5V로, 충전기 GND는 브레드보드 GND 레일에 연결해 공통 접지.
  신호선(GPIO13)은 그대로
- **핵심**: 전원이 두 계통이어도 GND는 반드시 하나로 묶는다. GND 미공유 시
  서보 오동작(떨림/무반응)
- **켜는 순서**: 충전기 먼저 → WROOM USB. 해제는 역순

### 마스트 단일 출력 실패 (최상단 부근)

- **증상**: 마스트 단일 출력 시 최상단 부근에서 2회 연속 실패
- **대응**: 상하 2피스 분할(97+107mm) + 플러그/소켓 결합으로 재설계

### 서보 플랜지 구멍 미정렬 (조립)

- **증상**: 서보 플랜지 구멍이 표준(49.5mm)보다 바깥이라 스탠드 파일럿과 미정렬
- **대응**: 나사 생략, 포켓 밀착 고정으로 진행 (필요시 케이블타이 보강).
  마스트-혼 결합은 M2 대신 글루건 사용

### 센서 헤더 핀 간섭 (조립)

- **증상**: 센서 헤더 핀이 뒷면으로 돌출되어 장착면에 평면 밀착 불가 (마스트 설계 누락)
- **해결**: 10mm 스페이서 삽입 (헤더 골 포함), 센서-스페이서 나사 결합 +
  스페이서-마스트 글루건 접착
